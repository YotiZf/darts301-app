Darts 301 Game App
A simple multiplayer 301 darts score tracker built with Python, Kivy, and Plyer.

This project lets players enter their names and countries, take turns, track scores from 301 down to 0, detect busts, and announce game events with text-to-speech. It was made as a fun darts app with a simple interface and voice reactions.

Features
Multiplayer setup

Player name and country input

301 score tracking

Turn-based gameplay

Bust detection

Round tracking

Winner detection

Text-to-speech voice feedback

Random reactions for special scores

Special message for the 1, 5, 20 throw combo: The Holy Trinity!

How the Game Works
Enter the number of players.

Enter each player's name.

Enter each player's country.

Every player starts with 301 points.

Each turn has up to 3 throws.

Enter the score after each throw.

If a throw makes the score go below zero, the player busts and the turn ends.

A player must reach exactly 0 to finish.

When all players finish, the app announces the winner or winners.

Special Score Reactions
The app reacts to some specific scores:

0 -> random bad-score message

1 -> random low-score message

2 -> joke message

20 -> country pride message

50 -> Bullseye

60 -> special praise message

1, 5, 20 in one turn -> The Holy Trinity!

Android Build
If you want to build this app as an Android APK, you can use Buildozer on Linux.

Basic steps
Install Buildozer and its system dependencies.

Make sure buildozer.spec is in the project root.

Run:

bash
buildozer android debug
The APK will be generated by Buildozer after the build finishes.

Notes
The text-to-speech feature depends on your platform and device configuration.

Kivy and Plyer may behave a bit differently on desktop and Android.

If you edit the code on mobile, be careful with Python f-strings and brackets, because a small missing quote or parenthesis can break the app.
